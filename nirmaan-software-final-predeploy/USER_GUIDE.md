# Nirmaan Software — Friend & User Guide

## Start
Open the private HTTPS link supplied by the Boss/Admin. Register with your own phone number and role. New non-Boss accounts stay pending until a Boss approves them and grants project access.

## Roles
- Boss/Admin: all projects, approvals, team access and oversight.
- Project Manager: manages assigned projects, tasks and site updates.
- Contractor: field-focused tasks and site updates with photos, camera, voice and transcript.
- Architect: assigned-project design/project visibility according to permissions.
- Client: simplified read-only project visibility plus permitted feedback.

## Sync
Nirmaan uses the shared server as the source of truth. The header shows Online, Syncing, or Offline. While logged in, the app refreshes shared data about every 15 seconds and immediately after reconnection. Do not assume an action saved if the app reports a network/server error.

## Install on phone
Open Nirmaan in Chrome/Safari/Edge and use **Install** or the browser's **Add to Home Screen** option. Camera and microphone require browser permission and HTTPS.

## Site updates
Authorized users can enter progress/text, upload multiple photos, capture from the camera, record a voice note and use browser speech recognition where supported. Review the transcript before posting.

## Privacy
Use individual accounts. Do not share passwords. Only grant users access to projects they should see. Log out on shared devices.
